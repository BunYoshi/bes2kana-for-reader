# BES Viewer for Screen Reader

点字データ（.bes形式）をカタカナに変換してブラウザに表示するツールです。

[このページから利用できます](https://BunYoshi.github.io/bes2kana-for-reader/)

ブラウザ上に表示されたテキスト全文を、ボタン一つでコピーすることも可能です。

スクリーンリーダーなどによる読み上げで聞き取りやすいように、囲み記号や見出し記号の位置に息継ぎを挟んだり、注釈記号などに特定の読み方を割り当てたりしています。

### 本プログラムで指定した記号類の読み方

- 注釈記号：　チュー
- 数字付きの注釈記号：　チュー　１　など
- 第１星印：　コメジルシ
- 第２星印：　ホシジルシ
- 第３星印：　ハナジルシ

※ 星印類は、内容に注目させるために行頭に記される※のような記号のことです。


## 対応ファイルフォーマット

- **.bes**: 日本国内で広く利用されている「点字編集システム」などの標準的なバイナリ形式の点字ファイル。

※サピエ図書館などからダウンロードした `.zip` 圧縮ファイルは、あらかじめ展開して `.bes` ファイルにしてから読み込んでください。


## 主な機能

- **点字ファイルの読み込み**: `<input type="file">` 経由での `.bes` 点字ファイルの読み込み。
- **カナ表示**: 点字から日本語（カタカナ）への変換およびテキスト表示。
- **PWA（Progressive Web App）対応**: オフライン環境でもビューアを起動して利用可能。

## iPhoneやiPadで点字データを仮名に変換して読む他のアプリ（1983hachigoro様より）

iPhoneやiPadで、.bes点字データを仮名に変換して読むことができるアプリには、下記のものなどがあります:

- [「BrailleTalk」](https://apps.apple.com/jp/app/brailletalk/id1067503021)

[ニュー・ブレイル・システム社](http://www.nbs.co.jp/) のiPhone用の優良アプリです。

Chromeブラウザで、サピエ図書館の点字データをダウンロードして、「ファイル」アプリに保存された.zipファイルを「共有」から「BrailleTalk」で開くことで、カタカナに変換された図書を音声で読むことができます。

しおり機能や、読み上げの設定変更などがあり、とても便利です。

- [ユニバーサルデザイン対応の電子書籍閲覧アプリ「UDブラウザ」](https://psylab.hc.keio.ac.jp/app/UDB/)

視覚障害などの学生が読みやすい教科書データを読むためのアプリですが、2026年9月のバージョンアップで、国会図書館の障害者サービス「みなサーチ」の検索・ダウンロードに対応しています。

pdfやデイジー図書に加えて、.bes点字データにも対応しているということです。

「みなサーチ」からダウンロードしたものでなくても、「ファイル」アプリにある点字データの.zipファイルも、「共有」から「UDブラウザ」で開くことができます。

ただ、2026年9月現在、私の使用環境では、変換された図書を、ページ送りしてうまく読むことができません。

環境の問題なのかもしれません。
